Detailed Description

Función básica de lectura del joystick integrado en la tarjeta Embedded Artist LPC4088.

Los pulsadores del joystick son activos a nivel bajo: cuando se pulsan ponen el correspondiente pin del microcontrolador a 0 y cuando están sin pulsar ponen el correspondiente pin a 1. Las conexiones entre el joystick el microcontrolador son:

Interno

Pin uC Dirección
P2[25] ARRIBA
P2[27] ABAJO
P2[23] IZQUIERDA
P2[26] DERECHA
P2[22] CENTRAL

Externo (leer2)

Pin uC Dirección
P0[24] ARRIBA
P0[23] ABAJO
P2[21] IZQUIERDA
P1[18] DERECHA
P0[27] CENTRAL

uint8_t joystick_leer ( void )

Leer el joystick del kit y retornar un número diferente según la dirección que se esté pulsando.

Return values
JOYSTICK_NADA/0si no se está pulsando ningúna dirección.
JOYSTICK_ARRIBA/1si el joystick está pulsado hacia ARRIBA.
JOYSTICK_ABAJO/2si el joystick está pulsado hacia ABAJO.
JOYSTICK_IZQUIERDA/3si el joystick está pulsado hacia la IZQUIERDA.
JOYSTICK_DERECHA/4si el joystick está pulsado hacia la DERECHA.
JOYSTICK_CENTRO/5si el joystick está pulsado hacia el CENTRO.
