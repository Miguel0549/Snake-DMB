Detailed Description

Macros y funciones para jugar al snake en el LPC4088 Developer's Kit con joystick y la pantalla del kit. Empiezas con una serpiente de 3 unidades de longitud, según comes frutas, de las cuales habrá siempre máximo 3, creces y ganas puntos. El objetivo es crecer al tamaño de la pantalla completa, que es de 14*7 unidades.
