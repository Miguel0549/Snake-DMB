Detailed Description

Constantes para utilizar el expansor de pines PCA9532.

Este dispositivo permite generar las señales de control de "reset" y "display_enable", controlar la tensión de alimentación a la LCD (3.3V o 5V) e intensidad de la retroiluminación de la pantalla LCD (genera una señal PWM el propio PCA9532).
