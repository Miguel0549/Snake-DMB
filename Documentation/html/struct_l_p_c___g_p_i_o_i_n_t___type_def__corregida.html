Detailed Description

Tipo estructura corregida del registro de interrupciones del GPIO del LPC40XX.

Los nombres de los registros de las interrupciones de los pines de los puertos P0 y P2 del fichero LPC407x_8x_177x_8x.h no están actualizadosa la última versión del manual del microcontrolador. Aquí se redefinen de forma que coincidan con el manual.
