Función de comprobación. 

Verifica si la condición {\ttfamily expr} es falsa y lanza un error indicando el archivo, función y linea donde se llamó a la función junto con un mensaje. Principalmente se utiliza para verificar los parámetros de entrada de las funciones para comprobar que se encuentran en los rangos correctos o se corresponden con los tipos adecuados (por ejemplo, punteros a periféricos).
